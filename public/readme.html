全方位 AI 數位內容創作夥伴

這是一個為數位內容創作者深度訂製的高效再製工具。不論您的原始素材是影音檔案、SRT/VTT 字幕或逐字稿，本工具皆能幫您整理內容，並延伸成 SEO 部落格文章、Google Blogger 草稿、多平台社群貼文、行銷電子報、社群輪播圖、資訊圖表與 YouTube 封面提示詞，集中完成從語音到發佈素材的工作流程。

本程式使用 Google Gemini 大語言模型，並可選擇自建 Cloudflare Whisper Worker 作為語音辨識引擎；各分頁依內容類型提供編輯、複製或下載功能。

目前版本：20260804R12

八大核心分頁功能

🎙️

語音轉文字辨識

支援 .mp3、.wav、.ogg、.m4a、.flac、.webm、.mp4。可選擇 Gemini 或自建 Cloudflare Whisper Worker，將語音轉成 SRT、純文字與 VTT；完成後可匯出檔案或送往「逐字稿整理」。

📝

智慧字幕整理

可貼上或拖曳匯入字幕與逐字稿，進行句末標點補全、長句分拆、時間軸平移、短句合併與間隔修復。提供 AI 校對建議、爆款主題配對、摘要、章節、複製與匯出 SRT；校對只套用使用者確認的項目，時間軸不會被任意改寫。

✍️

部落格文章生成

將整理後的內容重構為結構完整的文章，可設定人稱、字數、語氣與 CTA，並使用 AI 寫作風格精靈客製化結構、H2、粗體、表格、金句與語氣。提供多版本切換、Quill 編輯器、文章預覽、HTML/Markdown 原始碼、SEO 標題／搜尋描述／固定網址／標籤、關鍵字分析、內部連結建議及檔案下載。

📱

多平台社群貼文

一次生成 Facebook、Instagram、LINE 三種平台文案，可設定貼文目標、長度、語氣、Hashtags 與 CTA。支援 AI 社群風格精靈、核心觀點、開頭鉤子、平台專屬規則、多版本生成，以及目前平台內容複製。

✉️

行銷電子報

將內容依目標受眾與寫作風格整理成 HTML 電子報，包含主旨、問候、重點摘要與 CTA 按鈕。支援多版本生成與完整 HTML 複製，方便貼到電子報工具使用。

🎨

社群輪播圖規劃

專為 IG／FB 多圖輪播打造，可設定最多四個素材／角色、是否加入 Logo、說明文字長度、內容頁版型與視覺風格。一次規劃每一頁的文字與中英文繪圖提示詞，支援多版本、逐頁複製與全部複製。

📊

資訊圖表規劃

分析內容並自動推薦統計、資訊、時間軸、流程、比較、地理、階層或清單等圖表型態。可設定視覺風格、配色、尺寸比例、說明文字量與最多四個素材／角色，輸出中英文提示詞並支援複製與多版本。

🎬

YT 封面提示詞

從內容提煉吸睛的繁中封面標題與副標題，或直接套用「爆款主題」的完整配對。可設定最多四個角色／素材、Logo、鏡頭景別與藝術風格，產生固定六段結構、16:9、保留文字留白的繪圖提示詞，並支援多版本與複製。

快速上手指南

1

設定 Gemini API 金鑰

點選首頁狀態列旁的「設定金鑰」或側邊欄底部的「金鑰管理」按鈕，展開「📖 如何免費申請？」連結。依照教學，登入 Google 帳號並至 Google AI Studio 點擊 "Create API Key" 免費申請，將取得以 AIza 開頭的金鑰複製，貼回本工具儲存即可。本工具亦支援填入多組金鑰實現負載平衡輪替。
🎥 如何申請 Google API Key 教學影片 open_in_new

2

匯入並一鍵整理字幕檔

您可以至 DownSub 等網站下載您的 YouTube 影片 SRT 字幕檔。在「智慧字幕整理」分頁將字幕內容直接貼入或拖曳上傳至虛線匯入區。調整右側控制面板的「每行字數」、「最小合併字數」、「時間平移」、「間隔修復」滑桿，最後點選「智慧重整字幕」。完成語音辨識後，也可按「AI 校對建議」分批檢查疑似錯字與相同詞的一致性；所有建議預設不勾選，只有您確認的文字才會套用，字幕時間軸不會改變。完成後，可在此分頁直接點擊「生成摘要」與「生成章節」取得 AI 初步精簡報告。

3

一鍵生成部落格文章

整理好文稿後，前往「部落格文章生成」分頁。首選左側設定區的「最佳化文稿以提升寫作品質」，能大幅提升後續生成文章的流暢度與正確性。點選「風格客製化精靈」微調人設（如第一人稱、第三方導師）、字數與語氣。設定完成點擊「開始撰寫文章」，即可在右側編輯器獲得專業草稿，並支援 SEO 關鍵字與內部連結分析。

4

多軌擴展社群與視覺規劃

您可以根據剛產出的部落格文章或原始整理稿，切換至「社群貼文」、「行銷電子報」、「社群輪播圖規劃」、「資訊圖表規劃」或「YT 封面提示詞」頁面，一鍵生成不同平台的宣傳內容，形成全網覆蓋的數位內容行銷矩陣。

Google Blogger 發佈整合

在「部落格文章」分頁完成文章後，點選「發佈至 Blogger」。每位使用者都會以自己的 Google 帳號授權，並從該帳號可使用的 Blogger 網誌中選擇目標；本工具不共用你的 Google 帳號或 OAuth 存取權杖。

可用功能

  • 首次連結 Google 帳號並列出可用 Blogger 網誌。
  • 預設建立草稿；也可選擇建立後立即公開。
  • 自動帶入文章標題、HTML 內容與文章標籤。
  • 同一文章版本再次發佈時，會更新原本的 Blogger 文章。

目前限制

  • 永久網址與搜尋說明請到 Blogger 後台手動設定。
  • OAuth 存取權杖只保留在目前瀏覽器記憶體，不寫入 localStorage。
  • 送出前會移除危險 HTML 標籤，並避免重複送出文章 H1 標題。

設定步驟

  1. 在 Google Cloud 建立或選擇專案，啟用 Blogger API v3。
  2. 設定 OAuth 同意畫面，建立「Web application」OAuth Client ID，並在 Authorized JavaScript origins 加入本機網址與正式 HTTPS 網域。
  3. 本機開發：在專案根目錄建立 .env.local，填入 VITE_GOOGLE_BLOGGER_CLIENT_ID，再重新啟動或建置。
  4. Cloudflare Pages：在 Settings → Variables and secrets 的 Production 環境填入正式 Client ID；Preview 環境則填入測試用 Client ID。
  5. 將版本部署到 Production 後，從「部落格文章」分頁連結 Google Blogger 並測試建立草稿。

OAuth Client ID 是可公開使用的識別值，不要把 Client Secret 放進前端或提交到 Git。Google OAuth 應用程式若仍在 Testing 狀態，只有已加入的測試使用者可以授權；正式開放前請完成 Google Cloud 的發布與驗證要求。

關於 Cloudflare Whisper 運作原理與額度限制

⚙️ 它是如何運作的？

與傳統「將大檔案上傳到單一伺服器慢慢排隊處理」不同，Cloudflare 擁有遍佈全球的邊緣運算網路（Serverless GPU）。當您在本程式上傳長影音時，程式會在您的電腦端自動將音檔切成一小塊一小塊的碎片（例如每段幾十秒），並同時發送到您專屬的 Cloudflare Worker。
這時，Cloudflare 全球的伺服器會「平行處理」這些碎片，再將辨識好的文字瞬間拼裝回來還給您。這也是為什麼它的速度可以極快，且您無需擔心隱私外洩（因為資料只在您自己的帳號內流轉）。

💰 免費額度與限制

部署 Cloudflare Worker 本身是免費的，而使用其內建的 AI 模型（Workers AI）也提供了非常慷慨的每日免費配額：

  • 每日免費計算量：Cloudflare 每天提供 10,000 個「神經元 (Neurons)」的免費運算量。
  • 換算實際長度：對於 Whisper 語音辨識模型而言，這大約足夠您每天免費轉譯數小時長度的音檔。
  • 超量怎麼辦？即使您某天處理了超量影片，只要您沒在 Cloudflare 綁定信用卡開啟付費方案，系統只會拒絕請求而絕對不會擅自向您收費。程式會停止後續辨識、保留已完成字幕並顯示額度提醒；您可以等待每日額度重置，或自行升級 Workers Paid 方案。

💡 結論：對於一般創作者日常的 YouTube 影片、Podcast 逐字稿製作，Cloudflare 的免費額度幾乎等於「無限制」，加上完全掌握在自己手裡的隱私權，是一項極高性價比的隱藏神兵利器。

如何部署專屬的 Cloudflare Whisper Worker

為了使用更精準的 Whisper 語音辨識引擎，您需要部署專屬的 Cloudflare Worker 來作為 API 的中繼站。這不僅免費，且能確保您的辨識資料安全不外洩。請依循以下步驟從頭部署：

1

建立新的 Cloudflare Worker

請前往 Cloudflare 儀表板 並登入。在左側選單點選 Workers & Pages，接著點選 Create application -> Create Worker -> Start with Hello World!。

2

設定 Worker 網址

點選 Worker name ，填入你要的網址，這是 Worker API URL，用來填寫連線設定。填好後按下 Deploy。

3

貼上並部署程式碼

部署完成後，點選該 Worker 的 Edit code（或 Quick Edit）。將本專案目錄下 cf-worker/worker.js 的所有程式碼複製，並覆蓋掉編輯器內的預設程式碼。完成後，點擊右上角的 Save and Deploy。

4

啟用 Workers AI Binding (⚠️ 非常重要)

回到該 Worker 的設定頁面，點選畫面上方 Bindings，然後點擊 Add binding。選擇 Workers AI，並在 Variable name 欄位輸入 AI (必須全大寫且完全一致)。點擊 Save 儲存。

5

取得網址並設定驗證金鑰 (API Token)

為了保護 Worker 不被盜用，建議到 Settings -> Variables 頁面，新增一個環境變數：Type 選擇 Secret，Variable name 填寫 API_TOKEN，Value 填寫您自訂的密碼（例如 my-secret-token-2026）並點選 Deploy 儲存。

最後，請回到 ㄚ亮笑長的內容助手 程式左下角的「設定金鑰」選單，將您的 Worker 網址 (例如 https://yttb-whisper.your-name.workers.dev) 與剛剛設定的 Token 填入「Worker 連線設定」頁籤中並儲存，即可開始享受快速免費的高品質語音辨識服務！

常見問題與進階設定

Q1: 免費申請的 Gemini API Key 有限制嗎？

目前 Google AI Studio 提供的免費金鑰 (Gemini 2.5 Flash) 有每分鐘 15 次請求的限制。若您需要處理極大量的影片或文章，建議依照本程式金鑰設定提示，申請 2 到 3 組不同的免費金鑰一同填入，系統會自動在呼叫時進行智慧輪替，避免超出請求上限限制。

Q2: 程式有關閉頁面即清除金鑰的機制嗎？

有的。在您設定金鑰時，可以下拉選擇「金鑰保存期限」。如果您是在公用電腦操作，建議選擇「分頁關閉即清除」(存於 Session Storage)，當您將此瀏覽器分頁關閉後，所有 API 金鑰即會被自動銷毀抹除，無須擔心外洩。

Q3: 重新整理頁面後，編輯中的資料會保留嗎？

不會。為避免不同逐字稿與舊內容發生衝突，系統不再自動保存或恢復工作草稿。編輯內容與生成版本只會保留在目前開啟的頁面中；重新整理或關閉頁面前，請先使用各功能提供的下載或複製按鈕保存需要的內容。API Key、外觀與生成偏好等設定不受影響。
